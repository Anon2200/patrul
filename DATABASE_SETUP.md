# Подключение PostgreSQL для «Патрульной службы»

## Что добавлено

- Node.js HTTP-сервер (server.js).
- Проверка соединения: GET /api/health.
- Хранилище JSON по четырём ролям: nachalnik, zam, uchet, dokumentoved.
- Защита чтения и записи токеном Bearer.
- Контроль версии при записи: устаревшее сохранение получает HTTP 409 и не затирает более свежие данные.
- Таблица patrul_role_data создаётся сервером при старте.

## Переменные окружения сервиса ONREZA

1. DATABASE_URL — должна поступать из интеграции PostgreSQL; не публикуйте её.
2. PATRUL_API_TOKEN — длинный случайный секрет в секретах сервиса приложения. Не хранить в GitHub и не вставлять во frontend.

Команда запуска: npm start. Требуется Node.js 20 или новее.

## Проверка после настройки

Откройте /api/health на домене приложения. Успешный ответ: {"ok":true,"database":"connected"}.

## Важно

Это серверный фундамент. Четыре HTML-интерфейса пока продолжают использовать локальное хранилище браузера. Не вводите реальные служебные или персональные данные и не считайте синхронизацию включённой, пока frontend не будет отдельно переведён на API, а также не будут добавлены индивидуальные учётные записи и права доступа. Общий технический токен — временная серверная защита, а не полноценная система разграничения прав пользователей.
