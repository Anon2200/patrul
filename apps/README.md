# Приложения для ПК и Android

Оболочки над рабочим сайтом: данные остаются на сервере и общие для всех ролей, нужен интернет.

- `desktop/` — Windows (Electron, установщик `.exe`)
- `android/` — Android (Capacitor, файл `.apk`)
- `app-config.json` — адрес сайта для обоих приложений. Поменяли адрес — пересоберите.

## Где взять файлы
GitHub → Actions → **Build apps** → Run workflow, затем скачать `patrul-windows-installer` и `patrul-android-apk` из результатов запуска.
Для постоянной ссылки создайте тег `app-v1.0.0`: файлы появятся в разделе Releases.

## Установка
- **Windows:** запустить `Patrul-Setup-*.exe`. Windows SmartScreen может предупредить, потому что установщик не подписан: «Подробнее» → «Выполнить в любом случае».
- **Android:** скачать `Patrul.apk`, разрешить установку из этого источника. APK подписан отладочным ключом, в Google Play так не публикуют.
