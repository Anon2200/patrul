# Чистый запуск «Патруля»

Порядок для запуска с пустой базой. Данные прежней базы при этом теряются.

1. **Резервная копия.** Сделайте копию PostgreSQL, даже если данные не нужны: сброс необратим.
2. **Сброс базы.** `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f scripts/reset-database.sql`
   Убедитесь, что `DATABASE_URL` указывает на нужную базу (не на рабочую, если она нужна).
3. **Переменные окружения** (подробно в `LAUNCH_GUIDE_RU.md`): `DATABASE_URL`, `PATRUL_PUBLIC_ORIGIN`,
   `PATRUL_DATA_ENCRYPTION_KEY`, `PATRUL_BOOTSTRAP_SECRET`.
   Лучше сгенерировать **новый** ключ шифрования: старые зашифрованные данные уже удалены, ключ от них не нужен.
4. **Развернуть версию из `main`.** Команда запуска: `npm start` (или `node server.js`). Таблицы создаются автоматически.
5. **Первичная настройка:** создайте учётную запись Старшего мастера с секретом `PATRUL_BOOTSTRAP_SECRET`,
   затем остальные роли (раздел 3 `LAUNCH_GUIDE_RU.md`). После этого уберите `PATRUL_BOOTSTRAP_SECRET`.
6. **Приёмочная проверка** из раздела 4 `LAUNCH_GUIDE_RU.md`, включая раздел «Нарушители» у начальника,
   документоведа и старшего мастера.
7. **Кэш браузера.** Service worker хранит старые страницы: на устройствах один раз обновите сайт с очисткой кэша.
